Data Communications Concept: HTTP Round-Trip Time vs Host Reachability
When an HTTP client initiates a request, it performs DNS address resolution (mapping hostname to IP), completes a 3-way TCP handshake (SYN, SYN-ACK, ACK), executes TLS cryptographic negotiation (for HTTPS), and sends an HTTP GET header. The response time measured here encompasses the full application-layer round-trip time (RTT). A website returning HTTP 404 or 403 is still marked Reachable because the target web server actively received and responded to the packet.
