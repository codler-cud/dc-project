NEXUS is an academic diagnostic suite engineered to inspect web connectivity, measure internet download/upload speed with troubleshooting, continuously monitor HTTP round-trip latency with live statistical graphing, and simulate packet propagation dynamics across client, router, and server nodes.

Launch Connection Checker Explore Packet Simulator

Connection Checker

Verify real-world endpoint accessibility, exact HTTP status codes, DNS resolution, and server response times using real socket requests issued from the Python backend.

Open Checker

Internet Speed Checker

Measure real-time internet download and upload throughput modeled after Ookla and Fast.com. Features an interactive speedometer dial, live throughput sparkline graph, real binary upload streaming, and gaming/4K streaming suitability analysis.

Open Speed Checker

Latency Monitor

Sample HTTP application-layer round-trip time every 2 seconds. Automatically calculate live minimum, maximum, and average response times accompanied by a live line graph.

Open Monitor

Packet Simulator

Simulate packet flow across a classic 3-node topology: Client → Router → Server. Adjust channel transmission delay, packet loss rate, and inspect live packet delivery statistics.

Open Simulator
